# 8INF852 – Métaheuristiques en Optimisation

## Travail pratique 1

### Description
Implémentation et comparaison de trois métaheuristiques d'optimisation :
- **Random Search** : exploration aléatoire
- **Hill Climbing** : amélioration locale itérative
- **Simulated Annealing** : recuit simulé avec refroidissement

## Travail pratique 2

### Description
Implémentation et comparaison d'algorithmes métaheuristiques pour la génération de mots en français :
- **Algorithme génétique avec mutation** : optimisation par sélection et mutation
- **Algorithme génétique avec croisement** : optimisation par sélection et croisement
- **UMDA** : algorithme d'estimation de distribution univariée
